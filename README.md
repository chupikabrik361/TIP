## Сборка и запуск

Нужны CMake 3.16 или новее и компилятор с поддержкой C++14. В корне репозитория выполните:

```sh
cmake -S . -B build
cmake --build build --config Debug
```

Чтобы собрать только одну программу, укажите её цель. Например, для практической работы № 12:

```sh
cmake --build build --config Debug --target practice12
```

В CLion откройте корень репозитория как проект CMake и выберите нужную цель в меню запуска. При запуске из терминала исполняемые файлы обычно находятся в `build/`, а при использовании Visual Studio — в `build/Debug/`.

Файлы `.sb3` можно открыть в Scratch через **Файл → Загрузить с компьютера**.
